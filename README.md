# 🌿 ArecaGuard – Areca Palm Disease Detection and Targeted Pesticide Spraying System

## 📌 Project Overview

ArecaGuard is a smart agricultural system designed to support the detection of disease infection levels in areca palm plants and assist in targeted pesticide spraying.

The system analyzes the plant condition and categorizes the infection level as **Low, Medium, or High**. Based on the detected infection level, the system supports targeted pesticide application to reduce unnecessary pesticide usage and improve spraying efficiency.

The project combines plant image analysis, infection-level detection, and an Android-based interface to provide a practical solution for precision agriculture.

---

## 🎯 Objectives

- Detect disease infection levels in areca palm plants
- Classify plant infection as Low, Medium, or High
- Provide plant health status through a mobile application
- Support targeted pesticide spraying
- Reduce unnecessary pesticide application
- Improve pesticide usage efficiency
- Support precision agriculture practices
- Provide a simple interface for viewing detection results

---

## 🌱 Infection Levels

| Infection Level | Plant Status | Action |
|----------------|--------------|--------|
| Low | 🟢 Healthy / Low Infection | Limited or no spraying |
| Medium | 🟡 Moderate Infection | Targeted spraying |
| High | 🔴 Severe Infection | Higher targeted spraying |
